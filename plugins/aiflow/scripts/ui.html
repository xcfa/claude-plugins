Расход токенов

Проект, задачаМодельВходВыходКэш: чтениеКэш: записьЦена
Учитываются сессии задачи и их сабагенты; ревьюер opencode сюда не входит. «Токены» на доске — вход + выход + запись в кэш. Цена — оценка по тарифам API Anthropic с учётом модели и кэша (чтение из кэша дешевле входа, запись дороже): на подписке вы платите не за токены. Свои тарифы — prices в ~/.aiflow/config.json.

События

    Настройки
    Формат provider/model. Применяется со следующего раунда ревью; пустое поле — модель по умолчанию opencode.
    Пауза — у каждого проекта своя: работающие сессии доделают ход, новые не стартуют. Добавить проект — aiflow up в его каталоге; остановить службу и эту панель — aiflow down; фоновые сессии Claude при этом продолжат работать, остановить их — Ctrl+X в claude agents.
