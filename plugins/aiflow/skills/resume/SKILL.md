Монитор aiflow обычно запускается самим этим вызовом и поднимает службу aiflow. Выполни `aiflow status`.

Если в первой строке вывода есть «монитор не запущен» (так бывает в сессии, продолженной
через `claude --resume`: Claude Code не запускает в ней монитор плагина повторно), запусти
его сам инструментом Monitor: команда `aiflow run --events`, описание «Очередь aiflow»,
`timeout_ms` 1800000. Если инструмент Monitor не загружен, найди его через ToolSearch.
Команда поднимает службу aiflow (она ведёт очередь отдельно от сессий) и передаёт в чат
события этого проекта. Когда инструмент Monitor истечёт, не перезапускай его: служба и панель
продолжат работать, о важном пользователь узнает из системных уведомлений.
Если команда сразу завершится с ошибкой, запусти её же как
`"${CLAUDE_PLUGIN_ROOT}/bin/aiflow" run --events` — в PATH может стоять старая версия aiflow.

Затем одной-тремя строками сообщи пользователю, что ждёт его решения. Больше ничего не запускай.
