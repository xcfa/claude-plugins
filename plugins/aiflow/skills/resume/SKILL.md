Монитор aiflow обычно запускается самим этим вызовом. Выполни `aiflow status`.

Если в первой строке вывода есть «монитор не запущен» (так бывает в сессии, продолженной
через `claude --resume`: Claude Code не запускает в ней монитор плагина повторно), запусти
его сам инструментом Monitor: команда `aiflow run --events`, описание «Очередь aiflow»,
без ограничения по времени. Если инструмент Monitor не загружен, найди его через ToolSearch.
Второй монитор не запустится: если первый уже работает, команда тихо завершится.

Затем одной-тремя строками сообщи пользователю, что ждёт его решения. Больше ничего не запускай.
