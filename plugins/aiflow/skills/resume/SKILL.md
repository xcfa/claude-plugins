Монитор aiflow обычно запускается самим этим вызовом. Выполни `aiflow status`.

Если в первой строке вывода есть «монитор не запущен» (так бывает в сессии, продолженной
через `claude --resume`: Claude Code не запускает в ней монитор плагина повторно), запусти
его сам инструментом Monitor: команда `aiflow run --events --detach`, описание «Очередь aiflow»,
`timeout_ms` 1800000. Если инструмент Monitor не загружен, найди его через ToolSearch.
С `--detach` монитор работает отдельным процессом до конца этой сессии, а инструмент Monitor
только передаёт его события. Когда инструмент Monitor истечёт, не перезапускай его: монитор
и панель продолжат работать, о важном пользователь узнает из системных уведомлений.
Если монитор сразу завершится с ошибкой `unrecognized arguments: --detach`, в PATH стоит
старая версия aiflow: запусти его так же, но командой
`"${CLAUDE_PLUGIN_ROOT}/bin/aiflow" run --events --detach`.

Затем одной-тремя строками сообщи пользователю, что ждёт его решения. Больше ничего не запускай.
